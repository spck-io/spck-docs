# Встраивание редактора

Встройте Spck Editor в iframe для редактируемых примеров, учебных материалов и инструментов работы с кодом. Обёртка `SpckEditor` общается с iframe через `postMessage` и `MessageChannel`.

## <a name="screen-reader-support"></a>Поддержка экранных дикторов (экспериментальная)

Функции доступности и текущие ограничения описаны в разделе [поддержки экранных дикторов (экспериментальной)](./screen-reader-support#screen-reader-limitations). Встроенный редактор не включает мобильный режим редактирования с диктором автоматически.

Настройка, проекты и файлы, параметры редактора, события и устранение проблем описаны в [полной справке API на английском](/en/editor-embed). Код и объявления TypeScript находятся в [spckio/spck-embed](https://github.com/spckio/spck-embed).
