# Incorporar o editor

Incorpore o Spck Editor em um iframe para criar exemplos editáveis, tutoriais ou ferramentas de código. O wrapper `SpckEditor` comunica-se com o iframe por `postMessage` e `MessageChannel`.

## <a name="screen-reader-support"></a>Suporte a leitores de tela (experimental)

Veja [Suporte a leitores de tela (experimental)](./screen-reader-support#screen-reader-limitations) para recursos de acessibilidade e limitações atuais. O editor incorporado não ativa automaticamente o modo móvel de edição com leitor de tela.

A [referência completa da API em inglês](/en/editor-embed) descreve configuração, projetos e arquivos, opções do editor, eventos e solução de problemas. O código e as declarações TypeScript estão em [spckio/spck-embed](https://github.com/spckio/spck-embed).
