# <a name="getting-started"></a>Начало работы с Spck CLI

## <a name="overview"></a>Обзор

Spck CLI вышел из беты. Подключите компьютер к Spck Editor на телефоне или планшете для редактирования файлов, работы с Git и терминалами и просмотра локальных серверов. Используется зашифрованный ретранслятор или прямое соединение [Fast Lane](./cli#fast-lane) (Supporter и Gold).

## <a name="requirements"></a>Требования

Lite поддерживает редактирование проектов на вашем компьютере или публичной виртуальной машине через Spck CLI. Для удалённых проектов нужны **аккаунт Spck и активная подписка Spck**, отдельно от разовой покупки Lite. Подписка помогает покрывать постоянные расходы на хостинг, работу и обслуживание серверов Spck. Включённые локальные инструменты редактирования и Git по-прежнему доступны без подписки.

### Обязательные

- **Node.js**: **22.22.2+ (22.x), 24.15.0+ (24.x), или 26.0.0+** (`^22.22.2 || ^24.15.0 || >=26.0.0`).
- **Аккаунт Spck Editor**: Бесплатный аккаунт (30 мин/день) или Premium-подписка (без ограничений)
- **Мобильное приложение Spck Editor**: [Android](https://play.google.com/store/apps/details?id=io.spck) или [iOS](https://apps.apple.com/us/app/spck-editor/id1507309511)

### Необязательные (Рекомендуемые)

- **Git**: 2.20.0+ для [интеграции Git](./git-support#git-limitations-cli) в удалённых проектах
- **ripgrep**: 15.0.0+ для значительно более быстрого поиска файлов (улучшение в 100 раз)

## <a name="installation"></a>Установка

### Вариант 1: Запуск через npx (Без установки)

```bash
npx spck@latest
```

Запрашивает последнюю версию CLI — удобно для первой настройки или редкого использования. `npx spck` может повторно использовать установленную версию.

### Вариант 2: Глобальная установка

```bash
npm install -g spck
spck
```

Установите один раз и запускайте `spck` для повседневной работы. Обновление: `npm install -g spck@latest`. Для удалённых подключений по-прежнему нужен интернет.

## <a name="first-time-setup"></a>Первоначальная настройка

При первом запуске CLI интерактивный мастер настройки проведёт вас через следующие шаги:

### 1. Аутентификация

```bash
spck
# Нажмите ENTER для открытия браузера
# Войдите в аккаунт Spck Editor
# Авторизуйте CLI
# Вернитесь в терминал
```

Учётные данные сохраняются в `~/.spck-editor/.credentials.json` и сохраняются между сессиями.

Если браузер не может обратиться к localhost, вход выполняется через ретранслятор. QR-код входа или ссылка из CLI позволяют войти с другого устройства. Этот код отличается от QR-кода подключения к проекту.

### 2. Настройка проекта

Мастер настроит следующее:

- **Корневой каталог**: Базовый каталог для доступа к файлам (по умолчанию: текущий каталог)
- **Имя проекта**: Отображаемое имя в мобильном приложении (по умолчанию: имя каталога)

### 3. Интеграция с Git (Необязательно)

Если обнаружен файл `.gitignore`, CLI предложит добавить `.spck-editor/`, чтобы избежать случайного коммита секретных данных:

```
Add .spck-editor/ to .gitignore? (Y/n)
```

**Рекомендация**: Выберите `Y` для защиты учётных данных подключения.

### Повторный запуск настройки

Для повторной настройки в любое время:

```bash
spck --setup
```

## <a name="connecting"></a>Подключение к Spck Editor

Для нового проекта CLI показывает QR-код до первого успешного подключения редактора. Последующие запуски сразу открывают панель; нажмите **`c`**, чтобы снова показать QR-код и данные подключения, или **`l`** для логов. Увеличьте терминал, если QR-код не помещается.

### Способ 1: QR-код (Рекомендуется)

1. Откройте Spck Editor → **Проекты** → **Новый проект** → **Подключить удалённый сервер**
2. Нажмите значок QR-кода
3. Отсканируйте QR-код, показанный в терминале. Приложение подключится автоматически.

> 💡 **Примечание**: Код также можно отсканировать приложением «Камера» на устройстве — ссылка откроется в Spck Editor, если приложение установлено.

### Способ 2: Ручной ввод

Если отсканировать QR-код не удаётся:

1. Откройте Spck Editor → **Проекты** → **Новый проект** → **Подключить удалённый сервер**
2. Введите **ID клиента** и **Секрет**, отображаемые в терминале
3. Выберите ретрансляционный сервер, показанный в терминале
4. Нажмите **Подключить**

Если включено **Require PIN to connect**, введите PIN, выбранный на панели CLI. Приложение его не сохраняет. См. [PIN подключения](./cli-config#connection-pin).
