# Menyematkan Editor

Sematkan Spck Editor dalam iframe untuk membuat contoh yang dapat disunting, tutorial, atau alat pemrograman. Wrapper `SpckEditor` berkomunikasi dengan iframe melalui `postMessage` dan `MessageChannel`.

## <a name="screen-reader-support"></a>Dukungan Pembaca Layar (Eksperimental)

Lihat [Dukungan Pembaca Layar (Eksperimental)](./screen-reader-support#screen-reader-limitations) untuk fitur aksesibilitas dan keterbatasan saat ini. Editor sematan tidak otomatis mengaktifkan mode penyuntingan pembaca layar seluler.

[Referensi API lengkap dalam bahasa Inggris](/en/editor-embed) menjelaskan pengaturan, proyek dan berkas, konfigurasi editor, peristiwa, dan pemecahan masalah. Sumber serta deklarasi TypeScript tersedia di [spckio/spck-embed](https://github.com/spckio/spck-embed).
